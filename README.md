# Cyber Threat Intelligence Assessment
## OpenCTI + AlienVault OTX

## Project Overview

This project demonstrates a practical Cyber Threat Intelligence
assessment for a telecommunications organization.

The project involved deploying OpenCTI using Docker and integrating
AlienVault Open Threat Exchange (OTX) to collect and analyze
community threat intelligence.

## Objectives

- Analyze the telecommunications threat landscape
- Identify relevant threat actors and campaigns
- Analyze malware, tools and TTPs
- Investigate threats targeting Nigeria
- Integrate AlienVault OTX with OpenCTI
- Apply MITRE ATT&CK
- Apply the Cyber Kill Chain
- Apply the Diamond Model
